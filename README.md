# 티볼 타격 자세 교정 프로그램 — 사용 안내

초등 티볼 수업에서 학생의 타격 자세(뒷팔꿈치·뒷무릎 각도)를 측정하고 3단계로
피드백하는 프로그램입니다. 석사학위논문(RPISD 모형 기반 개발연구)의 산출물입니다.

- 저장소: <https://github.com/ekfrnsl33/tiball-batting-coach-v4>
- 이 README가 설명하는 버전: [v4.0 릴리스](https://github.com/ekfrnsl33/tiball-batting-coach-v4/releases/tag/v4.0)

> 요구사항명세서·개발 검증기록 등 연구 내부 문서와 학생 촬영 기록·이미지는
> 개인정보 보호를 위해 이 저장소에는 포함하지 않았습니다.

---

## 1. 실행하기 — 가장 쉬운 방법

Finder에서 이 저장소를 내려받은 폴더(예: `~/Desktop/tiball-batting-coach-v4`)를 열고
**`앱_실행하기.command`를 더블클릭**합니다.

1. 터미널 창이 열리고 **`Password:`** 가 나옵니다 → **맥 로그인 비밀번호**를 입력하고 Enter
   (타이핑해도 화면에 아무것도 안 보이는 것이 정상입니다)
2. 잠시 뒤 **브라우저가 자동으로 열립니다**. 안 열리면 직접 <http://127.0.0.1:5050> 을 엽니다
3. 카메라를 잡는 데 **10~20초** 걸립니다. 터미널에 `시도 3회 실패` 같은 메시지가 몇 번
   떠도 정상이며, 성공할 때까지 다시 시도합니다
4. 화면 왼쪽 아래가 `● 준비 완료`(초록색)가 되면 촬영할 수 있습니다

> **왜 비밀번호를 물어보나요?**
> macOS에서 RealSense 카메라를 다루려면 관리자 권한이 필요합니다. 프로그램이
> 인터넷으로 무언가를 하는 것이 아니라, 카메라 장치를 여는 데만 쓰입니다.

## 2. 끝내기

**터미널 창에서 `Ctrl + C`** 를 누릅니다. `^C`가 찍히고 프롬프트(`... %`)가 돌아오면
종료된 것입니다.

> ⚠️ **창을 그냥 닫으면 프로그램이 뒤에서 계속 돌아갑니다.**
> 그러면 다음에 켤 때 "이미 실행 중"이라며 안 켜집니다.
> 그럴 때는 **`앱_강제종료하기.command`를 더블클릭**하세요.

## 3. 터미널에 직접 입력하는 방법

더블클릭 대신 직접 입력하실 수도 있습니다. `응용 프로그램 → 유틸리티 → 터미널`을 열고:

```bash
cd ~/Desktop/tiball-batting-coach-v4   # 이 저장소를 내려받은 폴더
sudo ./venv/bin/python app.py
```

- 첫 줄: 프로그램이 있는 폴더로 이동
- 둘째 줄: 관리자 권한으로 프로그램 실행 (`./venv/bin/python`은 이 프로젝트 전용
  파이썬입니다. 맥에 원래 있는 파이썬과 섞이지 않게 따로 만들어 둔 것입니다)

## 4. 사용 순서

### ① 촬영 준비 화면

1. **학생 선택** — 드롭다운에서 연구용 코드를 고릅니다. 각 학생의 현재 단계와 누적
   횟수가 함께 표시됩니다
   - 전학생 등으로 학생이 늘면 `학생 추가 (전학생 등)`을 펼쳐 코드를 입력합니다
2. **타석 선택** — 좌타자 / 우타자. 이 선택에 따라 측정할 팔·다리가 정해집니다
3. **카메라 위치 맞추기** — 오른쪽 미리보기를 보면서
   - 카메라는 **학생의 배 쪽**, 양발을 이은 선과 **직각** 방향에 둡니다
   - 거리는 **2.5~3.5 m**
   - **초록 점선 안에 어깨·팔꿈치·손목·골반·무릎·발목이 모두** 들어와야 합니다
   - 화면 테두리가 **초록색**이 되면 준비 완료입니다. 노란색이면 아래 안내 문구가
     무엇을 고쳐야 하는지 알려줍니다
4. **촬영 시작 (스윙 3번)** 을 누릅니다

### ② 촬영 진행 화면

- 큰 숫자로 카운트다운이 나옵니다. 그 사이 학생이 자세를 잡습니다
- **테두리가 빨개지고 `스윙하세요!`가 뜨면** 스윙합니다
- **스윙 뒤에는 그대로 멈춰 있습니다** (다른 동작이 섞이면 타격 순간을 잘못 찾습니다)
- 이것을 3번 반복합니다
- 중간에 그만두려면 `촬영 취소하고 처음으로` 버튼을 누릅니다

### ③ 결과 확인 화면

- 등급(완벽 / 좋음 / 다시 연습)과 격려 문구
- 학생 모습 + 골격선 이미지
- 관절별 각도·기준각·차이·등급, 스윙 3번의 값
- 오른쪽에 현재 단계, 누적 횟수, 다음 단계까지 남은 횟수, 최근 판정 이력
- 아래 두 버튼으로 이동합니다
  - `(학생코드) 다시 촬영` — 같은 학생을 한 번 더
  - `처음으로 (다른 학생)` — 다음 학생으로

## 5. 카메라가 안 잡힐 때

터미널에 나오는 메시지에 따라 대처법이 다릅니다.

| 메시지 | 뜻 | 대처 |
|---|---|---|
| `시도 N회 실패 — failed to set power state` | 맥의 카메라 드라이버와 경합 중 | **정상입니다.** 계속 다시 시도하며 보통 몇 초 안에 성공합니다 |
| `시도 N회 실패 — Frame didn't arrive` | 같은 경합 상황 | **정상입니다.** 기다리세요 |
| `카메라가 USB에서 사라졌습니다 (No device connected)` | 장치가 USB 버스에서 빠짐 | **USB 케이블을 뽑았다 다시 꽂고** 프로그램을 다시 실행 |
| `이미 이 프로그램이 실행 중입니다` | 앞서 켠 것이 살아 있음 | `앱_강제종료하기.command` 더블클릭 후 다시 실행 |
| 카메라를 열지 못했습니다 (25번 모두 실패) | 권한·연결 문제 | ① 관리자 권한으로 실행했는지 ② **USB 3.0 이상** 케이블인지 ③ 케이블 재연결 |

**연결 시 주의**: USB 2.0 케이블로는 동작하지 않습니다. 카메라에 딸려온 케이블을
쓰시고, 가능하면 USB 허브를 거치지 말고 맥에 직접 연결하세요.

## 6. 저장되는 파일

모든 기록은 **이 컴퓨터 안에만** 저장됩니다. 네트워크나 클라우드로 나가지 않습니다.

```
data/
├── sessions_v4.csv       판정 기록 (엑셀로 더블클릭하면 열립니다)
├── students.json         학생별 단계·누적 횟수
└── results/
    ├── 보관안내.txt       보관·삭제 방침
    └── S1/               학생별 폴더 (첫 촬영 때 자동 생성)
        ├── 20260906_004512_shown.png      학생 모습 + 골격선 (얼굴 포함)
        └── 20260906_004512_skeleton.png   골격선만 (얼굴 없음)
```

- 파일 이름의 숫자가 촬영 일시이고, `sessions_v4.csv`의 촬영 일시와 짝을 이룹니다
- 논문에 실을 때는 얼굴을 가린 `_shown.png` 또는 `_skeleton.png`를 씁니다
- **원본 영상은 저장하지 않습니다.** 프레임은 처리한 뒤 버립니다
- `test_output/` 폴더는 개발·검증용 산출물입니다. 연구 기록과는 무관합니다

## 7. 자주 바꿀 만한 값

숫자만 고치면 되는 설정들입니다. 파일 위쪽에 모여 있습니다.

| 바꿀 것 | 파일 | 항목 |
|---|---|---|
| 판정 기준각·허용오차 | `judging.py` | `THETA`, `ALPHA`, `BETA` |
| 승급·강등 조건 | `judging.py` | `PROMOTE_AFTER`, `DEMOTE_AFTER` |
| 한 판정에 쓰는 스윙 횟수 | `app.py` | `SWINGS_PER_SESSION` |
| 녹화 길이·카운트다운 | `app.py` | `RECORD_SECONDS`, `COUNTDOWN_SECONDS` |
| 가시성 임계값 γ | `pose.py` | `VISIBILITY_THRESHOLD` |
| 해상도·프레임레이트 | `camera.py` | `WIDTH`, `HEIGHT`, `FPS` |

> ⚠️ `judging.py`의 기준각과 허용오차는 **전문가 그룹 검토를 거친 값**입니다.
> 임의로 바꾸지 마세요.

## 8. 파일 지도

### 앱을 돌리는 파일

| 파일 | 역할 |
|---|---|
| **`app.py`** | **진입점.** 웹 서버 + 카메라 작업 스레드. 이 파일만 실행하면 됩니다 |
| `camera.py` | RealSense 열기(macOS 드라이버 처리), 녹화, 노출 제어 |
| `pose.py` | MediaPipe로 관절 33개 추출, 골격선 그리기 |
| `capture.py` | 촬영·기록 만들기 (여러 화면이 공용으로 사용) |
| `depth_sampling.py` | 관절 위치의 거리 골라내기 |
| `angles.py` | 각도 계산, 임팩트 각도 직선 맞춤 |
| `impact.py` | 임팩트(타격 순간) 프레임 찾기 |
| `judging.py` | 판정·레벨업 (카메라 없이 동작하는 순수 계산) |
| `storage.py` | CSV·JSON 기록, 학생별 폴더, 학생 추가 |
| `preview_ui.py` | 프레이밍 확인 화면 그리기 |
| `textdraw.py` | 이미지에 한글 쓰기 |
| `templates/` | 웹 화면 (기본틀 + 사이드 메뉴 4개: 티볼 자세/촬영 준비/결과 확인/결과 해석 방법 + 촬영 진행 화면) |

### 개발·검증용 파일 (앱 실행에는 필요 없지만 지우지 마세요)

논문의 개발·검증 수치가 이 스크립트들로 나온 것이고, 문제가 생겼을 때 어디가
고장났는지 짚어내는 도구입니다.

| 파일 | 용도 |
|---|---|
| `test_camera.py` | 카메라 연결·심도 정렬 확인 |
| `test_pose.py` | 관절 추출 확인 |
| `test_angle.py` | 좌표 방식·심도 읽는 방법 비교 |
| `test_impact.py` | 임팩트 탐지 확인 |
| `test_exposure.py` | 노출 시간별 정확도 비교 |
| `test_judge.py` | 판정·레벨업 검증 (카메라 불필요) |
| `test_session.py` | 세션 전 과정 확인 (터미널 버전) |
| `preview.py` | 카메라 위치만 맞출 때 쓰는 단독 미리보기 |
| `reanalyze.py` | **저장된 데이터를 재촬영 없이 다시 분석** (카메라·관리자 권한 불필요) |
| `diagnose_camera.py` | 카메라가 지원하는 해상도·fps 전체 조회 |
| `grab_camera.py` | 카메라 잡기만 시험 |
| `chart.py` | 그래프 그리기 |

실행 예:

```bash
cd ~/Desktop/tiball-batting-coach-v4   # 이 저장소를 내려받은 폴더
./venv/bin/python test_judge.py                              # 카메라 불필요
./venv/bin/python reanalyze.py test_output/raw_impact.npz --side left
sudo ./venv/bin/python test_session.py --student S1 --side left
```

## 9. 알아두어야 할 제약

- **관리자 권한 필요** — macOS에서 RealSense를 열려면 필요합니다
- **USB 3.0 이상 연결 필요**
- 프로그램이 카메라를 잡는 동안 macOS의 카메라 드라이버(`UVCAssistant`)를 잠깐
  종료시킵니다. 시스템이 자동으로 되살리는 서비스라 안전하지만, 그 사이 다른
  앱(줌, 페이스타임 등)에서 카메라가 잠시 안 보일 수 있습니다
- 웹 화면은 **이 컴퓨터에서만** 열립니다(127.0.0.1). 다른 기기에서는 접속되지 않습니다
- 측정 정확도의 한계는 논문 본문에 정리해 두었습니다
